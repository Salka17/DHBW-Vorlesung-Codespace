## Von der Aufgabe zum Programm

Ein Programm führt konkrete Anweisungen aus, etwa für Berechnungen oder zur Automatisierung.

**Beispiel: Alter in Tagen berechnen**

1. Alter in Jahren entgegennehmen
2. Mit 365 multiplizieren
3. Ergebnis in Tagen anzeigen

**Eingabe → Verarbeitung → Ausgabe**

Eine genaue Schrittfolge zur Lösung einer Aufgabe heißt **Algorithmus**.

Note:
- Alltagsbeispiel sammeln
- Anforderungen: Eingaben, Regeln, erwartetes Ergebnis
- Pseudocode: Lösungsidee vor C#-Schreibweise
- 20 × 365 = 7300; Näherung ohne Schaltjahre/Geburtsdatum
- Lauffähig ≠ richtige Aufgabe gelöst

## Erstes C#-Programm

```csharp
Console.WriteLine("Hallo!");
Console.WriteLine("Programmierung mit C#.");
```

Ausgabe:

```text
Hallo!
Programmierung mit C#.
```

Anweisungen werden hier **von oben nach unten** ausgeführt.

Note:
- Quelltext vs. Ausgabe; zeilenweise vorhersagen
- C# = Sprache; Konsole = Text-Ein-/Ausgabe
- Syntax = Aufbau; Semantik = Bedeutung
- Beispiele: fehlendes Anführungszeichen vs. falscher Rechenfaktor

## Aufbau einer Anweisung

```csharp
Console.WriteLine("Hallo!");
```

| Bestandteil | Bedeutung |
|---|---|
| `Console.WriteLine` | Text oder einen Wert mit Zeilenumbruch ausgeben |
| `(...)` | Enthält den auszugebenden Text oder Wert |
| `"Hallo!"` | Ein Textwert; die Anführungszeichen begrenzen den Text |
| `;` | Beendet die Anweisung |

Note:
- Methode, Aufruf (), Argument "Hallo!"
- Klammern vs. Anführungszeichen; Syntaxzeichen nicht in Ausgabe
- WriteLine() ohne Argument → Leerzeile
- Semikolon bei Anweisungen, nicht pauschal bei jeder Codezeile
- Eigene Methoden später

## Zweck von Variablen

```csharp
Console.WriteLine(20);
Console.WriteLine(20 * 365);
```

Die Zahl `20` steht hier für ein Alter. Bei einer Änderung müssen beide Vorkommen angepasst werden.

Eine Variable speichert einen Wert unter einem **Namen**, über den er wiederverwendet werden kann.

Note:
- Problem: unklare Bedeutung, doppelte Zahl
- Wert einmal festlegen, mehrfach verwenden
- Nächste Folie: Zahl durch Namen ersetzen

## Variablen: Typ, Name und Wert

```csharp
int alter = 20;
Console.WriteLine(alter);
```

| Bestandteil | Bedeutung |
|---|---|
| `int` | Datentyp: eine ganze Zahl |
| `alter` | Name des Speicherplatzes |
| `=` | Wert zuweisen |
| `20` | Startwert |
| `;` | Ende der Anweisung |

**Deklarieren:** Variable anlegen. **Initialisieren:** ersten Wert zuweisen.

Note:
- Speicherfach: Beschriftung, Inhalt, erlaubter Typ; vereinfachtes Modell
- Grundform: Typ Name = Wert; int: 0, 20, -3
- WriteLine liest aktuellen Wert
- Deklaration + Initialisierung; heute direkt mit Startwert
- Getrennt: int alter; → alter = 20; erst danach lesbar; kein nutzbarer Standardwert 0
- Neustart: neu initialisiert; keine automatische dauerhafte Speicherung

## Variablenwerte und Literale

```csharp
int alter = 20;

Console.WriteLine(alter);
Console.WriteLine("alter");
Console.WriteLine(20);
```

Ausgabe:

```text
20

20
```

`alter` liest die Variable. `"alter"` ist ein wörtlicher Text. `20` ist eine Zahl.

Note:
- Ausgabe vorhersagen
- Literal = direkt geschriebener Wert
- alter vs. "alter"; Name lesen vs. Text
- 20 / "20" / '2'; true vs. "true"

## Datentypen im Überblick

| Typ | Vorzeichen | Größe | Wertebereich / Inhalt |
|---|---|---|---|
| `byte` | Nein | 8 Bit | 0 … 255 |
| `short` | Ja | 16 Bit | −2¹⁵ … 2¹⁵ − 1 |
| `int` | Ja | 32 Bit | −2³¹ … 2³¹ − 1 |
| `long` | Ja | 64 Bit | −2⁶³ … 2⁶³ − 1 |
| `char` | — | 16 Bit | Eine UTF-16-Codeeinheit, z. B. `'A'` |
| `float` | Ja | 32 Bit | Bis ca. ±3,4 × 10³⁸; ca. 6–9 gültige Ziffern |
| `double` | Ja | 64 Bit | Bis ca. ±1,8 × 10³⁰⁸; ca. 15–17 gültige Ziffern |
| `decimal` | Ja | 128 Bit | Bis ca. ±7,9 × 10²⁸; ca. 28–29 gültige Ziffern |
| `bool` | — | 8 Bit | `true` oder `false` |
| `string` | — | Variabel | Text, z. B. `"Inhalt"` |

Note:
- Ganzzahltypen: Vorzeichen und Grenzen; 8 Bit = 1 Byte
- Bereiche nachschlagen, nicht auswendig; int: −2 147 483 648 … 2 147 483 647
- char: UTF-16-Codeeinheit ≠ immer sichtbares Zeichen; string: variable Größe
- float/double: binär, begrenzte signifikante Ziffern
- Rundung: 1/3 dezimal, manche Dezimalbrüche binär nicht endlich
- decimal: Geld/Dezimalrechnung; ebenfalls begrenzt
- Wertebereich ≠ Genauigkeit ≠ Ausgabeformat
- Überlauf: byte 255/256; Überlaufprüfung später
- bool: zwei Werte; Größen ohne Verwaltungsaufwand
- Weitere Ganzzahltypen: sbyte, ushort, uint, ulong
- Referenzen: [Ganzzahltypen](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/integral-numeric-types), [Gleitkomma- und Dezimaltypen](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/floating-point-numeric-types), [sizeof](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/sizeof).

## Datentypen definieren

Die Schreibweise eines direkt angegebenen Werts (**Literal**) bestimmt seinen Typ — auch ohne eine Variablendeklaration:

- `"Inhalt"` → `string`: Text in doppelten Anführungszeichen
- `'a'` → `char`: eine UTF-16-Codeeinheit in einfachen Anführungszeichen
- `123` → `int`: eine ganze Zahl ohne Dezimalpunkt
- `123.45` → `double`: eine Zahl mit Dezimalpunkt
- `true` / `false` → `bool`: Wahrheitswerte ohne Anführungszeichen

Im C#-Code ist das Dezimaltrennzeichen immer ein **Punkt**.

Note:
- Literale haben eigenen Typ, auch ohne Variable
- Kleine Ganzzahlliterale: int; sehr große ggf. anderer Typ
- char: eine Codeeinheit; Beispiel 'a'
- Typ nach Bedeutung: Anzahl / Temperatur / Raum / Postleitzahl mit führenden Nullen
- Quellcode: Punkt; Ausgabe kulturabhängig
- 1_000_000 = 1000000; var später


---

## Spezifische Datentypen definieren

Ein **Suffix** legt den Typ eines Zahlenliterals gezielt fest:

| Literal | Typ | Beispiel einer Deklaration |
|---|---|---|
| `123L` | `long` | `long anzahl = 123L;` |
| `123.45F` | `float` | `float temperatur = 123.45F;` |
| `123.45D` | `double` | `double laenge = 123.45D;` |
| `123.45M` | `decimal` | `decimal betrag = 123.45M;` |

Ohne Suffix hat `123.45` bereits den Typ `double`.

Note:
- Suffixe groß/klein möglich; großes L lesbarer
- 36.6F für float; 36.6 bereits double
- L bestimmt Literaltyp, keine beliebige Bereichserweiterung
- M für decimal; D optional

## Typbindung und Zuweisungen

```csharp
int anzahl = 3;
anzahl = 4;          // Passt: eine ganze Zahl
```

Diese Zuweisungen passen nicht zu `int`:

```csharp
anzahl = "vier";     // Text statt Zahl
anzahl = 4.5;        // Zahl mit Nachkommastelle
```

Der **Compiler** prüft den Code vor der Ausführung und meldet solche Fehler.

Note:
- Zweites Codefeld absichtlich ungültig
- Typfehler live erzeugen, Meldung lesen, korrigieren
- Implizite Konvertierung: double wert = 123;
- double → int: möglicher Informationsverlust; keine automatische Zuweisung
- Text → Zahl: eigener Umwandlungsschritt

## Rechenoperatoren

| Operator | Bedeutung | Beispiel | Ergebnis |
|---|---|---|---|
| `+` | Addition | `10 + 3` | `13` |
| `-` | Subtraktion | `10 - 3` | `7` |
| `*` | Multiplikation | `10 * 3` | `30` |
| `/` | Division | `10 / 3` | `3` |
| `%` | Rest bei Ganzzahldivision | `10 % 3` | `1` |

Multiplikation und Division werden vor Addition und Subtraktion ausgewertet. Klammern legen die Reihenfolge fest: `(2 + 3) * 4` ergibt `20`.

Note:
- %: Rest, keine Prozentrechnung; 20 % → Faktor 0.20
- Rangfolge: *, /, % vor +, −
- 20 / 5 * 2 → 8; 20 / (5 * 2) → 2
- Zwischenschritte/Einheiten: 120 Min. → 2 Std.; 150 km / 2 Std. → 75 km/h
- Divisionstypen nächste Folie; Rest später für gerade/ungerade

## Ganzzahl- und Gleitkommadivision

```csharp
Console.WriteLine(5 / 2);      // 2
Console.WriteLine(5.0 / 2);    // 2.5 oder 2,5 in der Ausgabe
```

- Zwei `int`-Werte: Der Nachkommateil wird abgeschnitten.
- Mit einem `double`-Wert: Das Ergebnis kann Nachkommastellen haben.

```csharp
double ergebnis = 5 / 2;      // Speichert 2, nicht 2.5
```

Note:
- Zieltyp links ändert Rechnung rechts nicht
- 5 / 2 → 2; 5.0 / 2 → 2.5
- Abschneiden Richtung null: −5 / 2 → −2
- Quellcode Punkt; Ausgabe kulturabhängig
- Ganzzahldivision durch Laufzeitwert 0 → Fehler; Eingabeprüfung später

## Bedingungen und Programmablauf

Die bisherigen Beispiele führen alle Anweisungen der Reihe nach aus.
`if` (**wenn**) und `else` (**sonst**) ermöglichen einen bedingten Ablauf.

```text
                 Alter mindestens 18?
                    /           \
               wahr             falsch
                ↓                  ↓
        „Volljährig“       „Minderjährig“
                \                  /
                 → Weiter im Programm
```

Die Bedingung ergibt einen `bool`-Wert: `true` oder `false`.
Pro Durchlauf wird **genau einer** der beiden Zweige ausgeführt.

Note:
- Ohne Code mit 20/16 durchgehen
- Aktuellen Wert prüfen; kein Warten auf spätere Änderung
- Referenz: https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/selection-statements

## Syntax von `if` und `else`

```csharp [2|3-5|6-9|10]
int alter = 20;
if (alter >= 18)
{
    Console.WriteLine("Volljährig");
}
else
{
    Console.WriteLine("Minderjährig");
}
Console.WriteLine("Prüfung beendet.");
```

Note:
- Highlights: Syntaxteile, nicht Ablauf eines Programmlaufs
- () Bedingung; {} Block; Klammerpaare
- if (istVolljaehrig) direkt; Zahl 1 kein bool-Ersatz
- true → if; false → else; danach gemeinsame Ausgabe
- Nächste Folie zum Nachlesen

## `if` und `else`: Bestandteile

- `if (...)`: Die runden Klammern enthalten die Bedingung.
- `{ ... }`: Ein Block fasst die zugehörigen Anweisungen zusammen.
- Der `if`-Block wird ausgeführt, wenn die Bedingung `true` ergibt.
- Der `else`-Block wird ausgeführt, wenn die Bedingung `false` ergibt.
- Nach dem gewählten Block geht es mit der gemeinsamen Fortsetzung weiter.

Note:
- Nachschlagefolie; zügig weiter
- 20 → Volljährig; 16 → Minderjährig
- „Prüfung beendet.“ in beiden Fällen


---

## Klammern, Einrückung und Semikolon

```csharp
int alter = 20;
if (alter >= 18)
{
    Console.WriteLine("Volljährig");
    Console.WriteLine("Erwachsenentarif");
}
Console.WriteLine("Diese Ausgabe folgt immer.");
```

- **Kein `;` direkt nach `if (...)` oder `else`.**
- Die Anweisungen **im Block** enden hier jeweils mit `;`.
- Einrückung macht den Block lesbar; die `{ }` legen ihn fest.
- `else` ist optional: Bei `false` wird der `if`-Block übersprungen.

Note:
- Mit 16: Block übersprungen, letzte Ausgabe bleibt
- if (...); → leerer Anweisungskörper
- Immer {}; Einrückung allein ohne Wirkung
- Scope: lokale Variable nur im Block/inneren Blöcken
- Weiterverwendung: ticketpreis vorher anlegen; innen ändern, danach ausgeben

## Logische Operatoren: Bedingungen verknüpfen

| Operator | Bedeutung | Beispiel |
|---|---|---|
| `&&` | Und: beide wahr | `(alter >= 18) && hatTicket` |
| `\|\|` | Oder: mindestens eine wahr | `hatTicket \|\| stehtAufGaesteliste` |
| `!` | Nicht: Wahrheitswert umkehren | `!hatTicket` |

`hatTicket` und `stehtAufGaesteliste` sind hier `bool`-Variablen.

- `true && false` ergibt `false`.
- `true || false` und `true || true` ergeben `true`.
- `!true` ergibt `false`; `!false` ergibt `true`.

Note:
- Oder einschließlich: auch beide wahr
- Wahrheitstabelle: vier Kombinationen
- ! vor Wert/geklammerter Aussage
- Kurzschluss: && links false / || links true → rechts entfällt
- Heute ohne Seiteneffekte
- Referenz: https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/boolean-logical-operators


---

## Zusammengesetzte Bedingungen

```csharp [4]
int alter = 20;
bool hatTicket = false;
bool stehtAufGaesteliste = true;
if ((alter >= 18) && (hatTicket || stehtAufGaesteliste))
{
    Console.WriteLine("Zutritt erlaubt");
}
else
{
    Console.WriteLine("Kein Zutritt");
}
```

`true && (false || true)` → `true && true` → `true`.

Die äußeren `(...)` gehören zu `if`; die inneren gruppieren Teilbedingungen.

Note:
- Ausgabe: Zutritt erlaubt; Änderung für else suchen
- Rangfolge: ! vor && vor ||; lesbar klammern
- Altersbereich: jeden Vergleich vollständig schreiben
- !(Ticket || Gästeliste): weder noch; Unterschied zu !Ticket || Gästeliste
- Regel erst als Satz; Alternativen beide/keine testen
